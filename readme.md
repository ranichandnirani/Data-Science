## 📌 About This Repository

This repository documents my **job-ready Data Science journey** following CodeWithHarry's *[The Ultimate Job Ready Data Science Course](https://www.codewithharry.com/courses/the-ultimate-job-ready-data-science-course)*. From Python fundamentals to machine learning and deep learning, each module contains hands-on notebooks, real datasets, and practice projects.

**🎯 Course Goals:**

- 🐍 Master Python programming from a data science perspective
- 📊 Perform powerful data analysis using NumPy and Pandas
- 📈 Create data visualizations with Matplotlib and Seaborn
- 🗄️ Query and manage data using SQL
- 🎲 Understand statistics, probability & the Central Limit Theorem
- 🤖 Build and train Machine Learning models with Scikit-learn
- 🧠 Explore Deep Learning, Neural Networks & LLMs
- 🚀 Ship real, job-ready data science projects

## 🚀 Quick Start

### Prerequisites

```
✅ Python 3.10+
✅ VS Code or Jupyter Notebook
✅ Conda (recommended) or venv
✅ Git installed
✅ Basic terminal familiarity
```

### Installation & Usage

```
# Clone the repository
git clone https://github.com/ranichandnirani/Data-Science.git

# Navigate to the folder
cd Data-Science

# Choose any module (example: 0006_Data analysis using Pandas)
cd "0006_Data analysis using Pandas"

# Create and activate environment
conda create -n data-science python=3.10
conda activate data-science

# Install dependencies and launch Jupyter
pip install -r requirements.txt
jupyter notebook
```
